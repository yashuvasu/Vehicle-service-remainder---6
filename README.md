# 🚗 Vehicle Service Reminder System

A simple C program that tracks vehicle mileage and alerts users when service is due based on distance intervals.

---

## 📌 Features
- Calculates next service mileage  
- Shows remaining KM for next service  
- Alerts when service is due  
- Simple and user-friendly logic  

---

## 🧠 Concepts Used
- Functions  
- Conditional Statements  
- Input/Output Handling  
- Modular Programming  

---

## ⚙️ How It Works

The program takes:
- Current KM  
- Last Service KM  
- Service Interval  

And calculates:

Next Service = Last Service + Interval  
Remaining KM = Next Service - Current KM
